# AD Presenter
Software de Proyección Multimedia para Iglesias

AD Presenter es una solución profesional, rápida e intuitiva diseñada para proyectar letras, videos, imágenes y documentos en pantalla gigante de forma fluida durante servicios y alabanzas en vivo.

🚀 Características Principales

📚 Biblioteca de Canciones
Crea, edita y organiza tu repertorio de alabanzas fácilmente. Incluye ajustes de tono, BPM y líneas por diapositiva con formato automático inteligente.

🖼️ Gestión de Medios
Soporte completo para imágenes y videos de fondo. Aplica fondos dinámicos en tiempo real o proyéctalos directamente durante tus presentaciones.

📄 Visor de Presentaciones PDF
Importa archivos PDF para prédicas, anuncios o presentaciones de diapositivas con navegación rápida entre páginas.

🔄 Importación y Exportación
Compatibilidad total con formatos JSON, TXT y CSV para respaldar o compartir tu catálogo musical en segundos.

✏️ Corrector Ortográfico Nativo
Sugerencias ortográficas integradas en español para garantizar letras impecables y sin errores durante el servicio.

🎨 Plantillas de Proyección
Elige entre fondo blanco, caja principal o fondo con imagen para tus letras. Aplica el estilo a todo el servicio con un clic desde la pestaña Plantillas.

📱 Control Remoto Web
Controla diapositivas, canciones y alertas desde cualquier smartphone o tablet en la red local, sin instalar nada. Solo escanea el código QR y controla en tiempo real vía Wi-Fi.

🔌 Ecosistema de Plugins (Post-Lanzamiento)
Tras la versión oficial (23 de agosto), se añadirá una arquitectura de complementos personalizados según las necesidades específicas de cada iglesia.

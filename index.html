Diseñado para el Control Total en Vivo

Herramientas avanzadas pensadas para los equipos de medios y producción en iglesias.

Biblioteca de Canciones

Crea, edita y organiza tus alabanzas fácilmente. Ajusta tono, BPM y líneas por diapositiva con formato automático inteligente.

Gestión de Medios

Soporte completo para imágenes y videos de fondo. Aplica fondos dinámicos en tiempo real o proyéctalos directamente.

Visor de Presentaciones PDF

Importa archivos PDF para prédicas, anuncios o presentaciones de diapositivas con navegación rápida entre páginas.

Importación y Exportación

Compatibilidad total con formatos JSON, TXT y CSV para respaldar o compartir tu catálogo musical en segundos.

Corrector Ortográfico Nativo

Sugerencias ortográficas integradas en español para garantizar letras impecables y sin errores durante el servicio.

Control Remoto Web Próximamente

Servidor HTTP + Socket.io integrado para controlar las diapositivas y el proyector de forma remota desde cualquier smartphone o tablet en la red local.

Ecosistema de Plugins Post-Lanzamiento

Tras la versión oficial (23 de agosto), añadiremos una arquitectura de complementos personalizados según las necesidades específicas de cada iglesia.
